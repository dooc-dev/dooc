# 功能体验区

这个临时工作区可以体验编辑、预览、结构化记录和插件。重新运行 `mise run editor` 会恢复初始内容；运行期间的热重载会保留编辑内容。

| 功能 | 打开页面 |
| --- | --- |
| Markdown编辑、保存和验证 | [编辑练习](contents/md/playground.md) |
| 图表、表格、术语和提示块 | [内容块示例](contents/md/blocks.md) |
| 图片、视频、HTML、PDF和CAD | [媒体示例](contents/md/media.md) |
| 日期、选项、数字、布尔值和嵌套字段 | [表单示例](contents/md/form-controls.md) |
| 关联的JSON、YAML和TOML记录 | [Atlas项目](contents/md/atlas.md) |
| 工单、代码审查和讨论 | [本地集成](contents/md/integrations.md) |
| 分支、历史和文档版本 | [历史示例](contents/md/history.md) |

使用页面语言菜单切换英语、日语和中文。未提供翻译的页面会显示英文原文。也可以为其他页面添加语言并编辑翻译文件。

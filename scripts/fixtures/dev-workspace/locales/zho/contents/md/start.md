# 功能体验区

这个临时工作区可以体验编辑、预览、结构化记录和插件。重新运行 `mise run dev` 会恢复初始内容；运行期间的热重载会保留编辑内容。

## 二级标题

比较各级标题的大小和上方间距。折叠本节时，下属的三级至六级标题及其内容也会一起隐藏。

### 三级标题

这个小节属于上面的二级标题。

#### 四级标题

标题越小，上方的间距也越小。

##### 五级标题

链接按钮可以复制本节的网址，箭头可以折叠本节内容。

###### 六级标题

这是最深的标题层级。也可以在源码编辑器中折叠同样的层级。

## 另一个二级标题

折叠前一个二级标题时，这个同级标题仍然可见。

# 体验各项功能

新的一级标题也有竖线标记。折叠第一个一级标题时，从这里开始的内容仍然可见。

# 機能プレイグラウンド

編集、プレビュー、レコード、プラグインを試せる一時ワークスペースです。`mise run dev` を起動し直すと初期状態に戻ります。起動中のホットリロードでは編集内容が維持されます。

## レベル2の見出し

見出しのサイズと上の余白を見比べてください。ここを閉じると、配下のレベル3〜6もまとめて閉じます。

### レベル3の見出し

上のレベル2に属する小見出しです。

#### レベル4の見出し

小さな見出しほど、上の余白も小さくなります。

##### レベル5の見出し

リンクボタンでこの節のURLをコピーし、矢印で本文を折りたためます。

###### レベル6の見出し

最も深い見出しです。ソースエディタでも同じ階層を折りたたんでみてください。

## もうひとつのレベル2の見出し

直前のレベル2を閉じても、この兄弟見出しは表示されたままです。

# 機能を試す

新しい大見出しにも縦バーが付きます。最初の大見出しを閉じても、ここから先は表示されたままです。

| 試す機能 | 開くページ |
| --- | --- |
| Markdownの編集・保存・検証 | [編集用ページ](contents/md/playground.md) |
| 図・表・用語・コールアウト | [ブロックの実例](contents/md/blocks.md) |
| 画像・動画・HTML・PDF・CAD | [メディアギャラリー](contents/md/media.md) |
| 日付・選択肢・数値・真偽値・入れ子 | [フォームの実例](contents/md/form-controls.md) |
| 関連するJSON・YAML・TOMLレコード | [Atlasプロジェクト](contents/md/atlas.md) |
| チケット・レビュー・会話 | [ローカル連携](contents/md/integrations.md) |
| ブランチ・履歴・バージョン | [履歴の実例](contents/md/history.md) |

ページの言語メニューで英語・日本語・中国語を切り替えられます。このページ以外の翻訳がないページは英語で表示されます。別のページにも言語を追加し、翻訳ファイルを編集してみてください。

## 読み手が判断できる記事にする

最初に目的を書き、手順、結果、補足の順に説明します。1ページで扱う話題を絞り、詳細は子ページに分けます。

| 表現     | 適した内容           | サンプル                        |
| -------- | -------------------- | ------------------------------- |
| 箇条書き | 条件や確認項目       | [公開前チェック](doc\:a)        |
| 図・HTML | 構成や処理の流れ     | [図とHTML](doc\:media)          |
| 関係図   | コンポーネントの依存 | [処理フロー](doc\:flow)         |
| スキーマ | テーブル間の関連     | [データモデル](doc\:data-model) |

## コードを載せる

コードフェンスに言語を指定すると、構文を色分けして表示します。

```ts
const document = {
    id: "getting-started",
    title: "はじめに",
    tags: ["ガイド"],
};
```

## ファイルをそのまま載せる

`textfile` は、ファイル名付きの枠にファイルの内容を表示します。この例では `examples/hello.rs` を読み込み、拡張子 `.rs` からRustの構文を色分けします。

:::textfile(examples/hello.rs)

```md
:::textfile(examples/hello.rs)
```

パスは docs root からの相対パスです。閉じ行は不要です。エディタでは参照行の右隣にある開閉ボタンを押して編集・保存できます。存在しないパスは「ファイルが見つかりません」と表示され、エディタから新規作成できます。開閉・整形・保存・再読み込みのボタンは参照行の隣に並びます。整形はMarkdown本体と同じ言語別の設定を使い、保存するまでファイルには反映されません。

### 一部分だけを載せる

末尾の `[2,3]` で2行目から3行目だけを表示できます。背景は透過で、右上の枠線上にファイル名を表示します。

:::textfile(examples/hello.rs)[2,3]

```md
:::textfile(examples/hello.rs)[2,3]
```

文字位置や文字列による指定も[記法一覧](doc\:syntax)にあります。範囲指定は表示だけに適用され、展開エディタは元ファイル全体を扱います。枠にカーソルを合わせると、元のパスと範囲指定を確認できます。

### URLをそのまま載せる

ファイルのURLやGitHubのファイルページURLも直接指定できます。Gitリポジトリの場合は `#ブランチ:ファイルパス` を付けます。

```md
:::textfile(https://example.com/hello.rs)[2,3]
:::textfile(https://github.com/owner/repo/blob/main/src/hello.rs)
:::textfile(https://example.com/repo.git#main:src/hello.rs)["fn main", *]
```

URLのファイルは展開して内容を確認できますが、読み取り専用です。取得結果は1分間保持され、「ファイルを再読み込み」で更新できます。参照先が無い場合や取得できない場合も、本文は表示されます。

## 補足を目立たせる

:::callout[リンクと用語をそろえる]
- 他の文書には doc: リンクを使います。
- docs root や artifact のような共通用語は用語集にまとめます。
- 図には、何を読み取れるかを示すキャプションを付けます。
:::

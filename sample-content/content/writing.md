## 読み手が判断できる記事にする

最初に目的を書き、手順、結果、補足の順に説明します。1ページで扱う話題を絞り、詳細は子ページに分けます。

| 表現 | 適した内容 | サンプル |
| --- | --- | --- |
| 箇条書き | 条件や確認項目 | [公開前チェック](doc:a) |
| 図・HTML | 構成や処理の流れ | [図とHTML](doc:media) |
| 関係図 | コンポーネントの依存 | [処理フロー](doc:flow) |
| スキーマ | テーブル間の関連 | [データモデル](doc:data-model) |

## コードを載せる

コードフェンスに言語を指定すると、構文を色分けして表示します。

```ts
const document = {
    id: "getting-started",
    title: "はじめに",
    tags: ["ガイド"],
};
```

## 補足を目立たせる

:::callout[リンクと用語をそろえる]
- 他の文書には doc: リンクを使います。
- docs root や artifact のような共通用語は用語集にまとめます。
- 図には、何を読み取れるかを示すキャプションを付けます。
:::

書き終えたら[公開前チェック](doc:a)で内容を確認します。

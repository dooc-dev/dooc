title: "File preview gallery"
---

Small, local examples of the formats dooc can display. Each page keeps its source files in the file card so you can inspect the original.

| Collection | Formats |
| --- | --- |
| [Images](files/md/images.md) | SVG, PNG, JPEG, WebP, GIF |
| [Data](files/md/data.md) | CSV, TSV, JSON, YAML, TOML, XML |
| [Code](files/md/code.md) | TypeScript, JavaScript, Python, Rust, SQL, CSS, shell, text |
| [Diagrams](files/md/diagrams.md) | Mermaid, graphth, schemath |
| [Document blocks](files/md/documents.md) | Markdown, callouth, termth, HTML |
| [Video](files/md/video.md) | MP4, WebM |

An embed stores a path, not a copy of the file. Edit the original to update every place that references it.

Editor with Split view enabled.

Scroll the diagram horizontally to inspect each area.

Sidebar
The site title, document tree, and workspace tools. Close it to give the page more room.
Resize sidebar
Drag the sidebar's right edge to change its width.
Preview pane
The rendered page. Click a pane to make it active; navigation and editing then apply to that pane.
Pane actions
Preview theme, reader font, and page language. These controls are hidden inside the development pane.
Second pane
Split view adds another preview with its own page, language, theme, and workspace selection.
Resize editor
Drag the separator at the editor panel's left edge, or focus it and use the arrow keys.
Editor panel
The right side of the editing screen: an editor header above the source editor.
Editor header
Page language, workspace and branch, validate, save, split view, view settings, and open workspace.
Source editor
The Markdown, record, or schema for the active page, with diagnostics as you type.

In Reader

The reader keeps the sidebar and one rendered page. There is no source editor; page actions offer the preview theme and reader font.

Header above the source editor, with Split view enabled.

Scroll the diagram horizontally to inspect each area.

Page language
Select the page language or use Add translation. This changes document content, not the language of the application controls.
Workspace and branch
Select the workspace and branch for the active pane, or use Create branch. Split view shows one selector per pane; the active pane is underlined.
Validate and apply
Format and check the whole page. Shortcut: Shift+Alt+F. Inspect any diagnostics before continuing; publishing remains a separate build step.
Save
Write the page to its workspace. Shortcut: Ctrl+S. Auto save performs this automatically when enabled.
Split view
Open or close a second preview pane. Each preview keeps its own page, language and workspace selection.
View settings
Choose editor theme, editor font and application language. Toggle Auto validate, Auto save, Source mapping, Show Git changes and Wrap lines. Preview theme and viewer font remain in the preview pane.
Open workspace
Open a local folder, browser workspace, Git clone or server connection for the active pane.

The document tree and workspace tools in edit mode.

Scroll the diagram horizontally to inspect each area.

Site icon
The icon from left_sidebar.icon. In edit mode, select it to replace the SVG.
Site title
The title from left_sidebar.title in the current language. In edit mode, select it to rename the site.
Close sidebar
Collapses the sidebar; the same control expands it again.
Document tree
Pages, boards and Library pages from center_contents. Tree edits rewrite dooc.yaml.
Page row
The page icon, title and a chevron for children. Select a page to open it; row actions rename, move or change its icon. Renaming updates references.
Add a page
Creates a Markdown page, a record board or a Library page at that position in the tree. The diagram shows the add control beside the selected row.
Workspace tools
A foldable group named after the open workspace. The tools below act on that workspace.
Files
Browse, upload, rename and reorganize files; copy a path for an embed. History saves and restores snapshots where supported.
Library
Find blocks, code fences, URLs and terms, and see where they are used.
Subformats
Open record boards, register a type and edit its schema.
Plugins
Add, enable and sign in to plugins. Add plugins accepts a dropped plugin file.
Git
Stage, commit, switch branch, fetch, pull and push. Available actions depend on the workspace connection.

In Viewer

Navigation remains available. Editing actions such as renaming the site or adding a page are not shown.

The editor header sits above the source editor and acts on the active pane. Use it to select the editing context, validate and save the current page, and change the editor's display settings.

![Editor header](contents/html/ux-header.html)

## Follow an action

| Action | Guide |
| --- | --- |
| Edit, format and save a page | [Using the editor](contents/md/editor.md#edit-and-save-a-page) |
| Compare workspaces or branches in split view | [Workspaces and branches](contents/md/workspaces.md#workspaces-and-branches) |
| Add a content translation | [Themes and languages](contents/md/variants.md) |
| Configure formatters and linters | [Code tools](contents/md/code-tools.md) |
| Open a browser workspace or remote session | [Workspace storage](contents/md/workspaces.md) |

Return to [Screen layout](contents/md/ux-layout.md) to see where this header sits. The [sidebar](contents/md/ux-sidebar.md) contains page navigation and workspace tools.

| Try               | How                                                    |
| ----------------- | ------------------------------------------------------ |
| Read the diff     | Expand **files changed**                               |
| Change the status | Turn on **Edit**, double-click **Status**              |
| Comment           | Write in the composer; edit or delete your own comment |
| Compact view      | **Collapse card** shows title, status, and checks      |

Deleting a comment asks for confirmation: the plugin marks that action as destructive.

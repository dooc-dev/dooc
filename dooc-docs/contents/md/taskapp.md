| Try                 | How                                                                     |
| ------------------- | ----------------------------------------------------------------------- |
| Edit a field        | Turn on **Edit**, double-click the title, status, assignee, or due date |
| Edit Markdown       | Open the description or the checklist; it renders again on save         |
| Pick several values | **Labels** is a multi-select                                            |
| Comment             | Write in the composer under **Comments**                                |

A plugin declares each editable field with a type: text, textarea, select, multi-select, date, or number.

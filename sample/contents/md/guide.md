title: "Meet dooc"
---

dooc turns Markdown and local files into a document workspace. Keep diagrams, code, data, and service links beside the text that explains them.

## One folder, readable anywhere

- Write in Markdown and preview changes as you edit.
- Embed local files with `![](path/to/file)`.
- Keep navigation in `dooc.yaml` and source files in Git or storage.
- Share the source folder or export a standalone HTML document.

## A small workflow

Open a page from the tree, edit its Markdown, and validate the result. Use the file card to browse supporting material. The split-view control lets you compare two pages, languages, or themes.

The editor theme controls both sidebars. Each document pane has its own theme picker beside the language icon.
